# H3 營運儀表板：測試報告

- 日期：2026-11-03
- 截圖：`docs/過程截圖/H3_儀表板/`（含配色驗證結果）

## 做了什麼
| 項目 | 內容 |
|---|---|
| API | `GET /api/admin/dashboard?days=14`（業務以上）：近 30 天關鍵數字、近 N 天每日趨勢（7～90 天）、熱門行程、報價來源 |
| KPI | 近 30 天報價數（含 AI 客服張數）、成交數與成交率、成交金額、AI 花費與對話數、待處理事項（待核准採購＋ERP 失敗＋待處理轉接） |
| 圖表 | 每日成交金額、每日報價數、熱門行程（橫條）、報價來源（比例條＋圖例）、AI 每日花費 |
| 日期 | 每日資料用台灣日期分組；沒有資料的日子補 0，橫軸不缺日期 |
| 製作方式 | 純 SVG／HTML（`frontend/charts.js`），不依賴外部圖表套件，安裝版離線也能顯示 |
| 設計規範 | 依 dataviz 指引：柱子最寬 24px、頂端 4px 圓角、細格線、單一數列不放圖例、兩類以上有圖例、文字用文字色、滑過顯示數值、每張圖附「看數據表格」 |
| 配色驗證 | 藍 #2a78d6、橙 #eb6834 在白底：色盲辨識 ΔE 24.7（標準 ≥ 8）、一般視覺 ΔE 33.6、對比 ≥ 3:1，全部通過 |
| 示範資料 | `seed_demo.py` 加入 26 筆過去 13 天的模擬歷史報價（固定亂數種子、姓名遮蔽成「林○華」），今天的資料用真實流程與真實 AI 產生 |

## 發現並修正
- 張數刻度出現 2.5：整數資料的中間刻度改為整數。
- 座標軸文字太小（SVG 縮放後只剩約 8px）：放大字級。
- 畫面回歸測試找不到「下載 CSV」：登入後預設改顯示儀表板，測試要先切到報價分頁。
- 滑過提示的截圖被切掉：提示框浮在圖表外，截圖範圍放大。

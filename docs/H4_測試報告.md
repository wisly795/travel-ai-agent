- 日期：2026-11-03

## 做了什麼
| 項目 | 內容 |
|---|---|
| 合作夥伴 API | 獨立子應用 `/partner`：目的地、行程、飯店、試算、建立報價（出發日期必填）、查詢自己建立的報價 |
| 驗證 | `X-API-Key` 標頭；金鑰格式 `pk_…`，資料庫只存 SHA-256 雜湊與前 10 碼；停用立即失效 |
| 呼叫上限 | 每個合作夥伴各自設定每分鐘上限（預設 30），超過回 429 並附 `Retry-After: 60` |
| 呼叫紀錄 | `partner_calls`：每次呼叫的路徑與結果（含被擋下的 429），用來計算上限與給管理員查看 |
| 資料隔離 | 合作夥伴只能查自己建立的報價，別家的回 404（不透露是否存在） |
| API 文件 | `/partner/docs`（Swagger UI）、`/partner/openapi.json`；主系統的 API 文件仍關閉 |
| 管理 | 管理員在「系統管理」建立合作夥伴（金鑰只顯示一次）、停用、看 24 小時呼叫數與被限流次數、最近呼叫 |
| 模擬官網 | 新服務 `website`（port 8103，「晴空旅遊」）：官網伺服器帶金鑰呼叫 API，客人在官網查行程、線上報價；瀏覽器看不到金鑰 |
| 報價來源 | 新增「官網串接」；後台、CSV、儀表板來源圖都會顯示；三色配色經驗證通過（綠色對比 2.82 以圖例文字與數據表格補足） |

## 瀏覽器實測
模擬官網查京都行程 → 線上報價完成（報價單、總價、出發與回程日）→ 頁面原始碼沒有金鑰 → 後台報價來源顯示「官網串接」→ 管理員建立合作夥伴並看到「只顯示一次」的金鑰 → 儀表板來源三類 → API 文件頁。

## 發現並修正
- 測試腳本網址含中文「沖繩」沒有編碼，Python 送出時報 UnicodeEncodeError；改用 `urllib.parse.quote`。（見錯誤紀錄 H4-1）

## 已知限制
- API 文件頁（Swagger UI）的畫面元件從網路載入，離線時文件頁打不開（`/partner/openapi.json` 仍可用）。
- 呼叫上限以資料庫計數，適合小流量；大流量要改用 Redis 等快取。

## 2. 真實 Claude 端到端（`tools/live_rag_test.py`）
| 客人問 | AI 表現 | 結果 |
|---|---|---|
| 出發前 7 天取消，團費 107,200 退多少？ | 查規定＋計算退費工具：扣 50%，退 NT$ 53,600，附來源第 3 條 | ✅ |
| 人數不夠會不會開團？ | 換說法再查，找到第 5 條：未達 10 人不成團，出發前 7 天通知，全額退費 | ✅ |
| 去沖繩要辦簽證嗎？ | 日本 90 天免簽，附來源第 2 條；其他護照說文件沒提到，可轉專人 | ✅ |
| 充電寶可以託運嗎？ | 不可託運，須放手提，附來源行李規定第 4 條 | ✅ |
| 三歲小孩怎麼收費？ | 佔床同成人價、不佔床 80%，附來源第 1 條 | ✅ |
| 可以在飛機上抽菸嗎？ | 查了兩次，說文件沒有提到，建議問航空公司或轉專人，沒有用常識亂答 | ✅ |
| 可以帶倉鼠嗎？ | 不接受寵物（服務犬除外），附來源第 5 條 | ✅ |
| 4 人沖繩每人 3 萬，順便問簽證 | 同一回答裡用查行程＋查規定兩個工具 | ✅ |

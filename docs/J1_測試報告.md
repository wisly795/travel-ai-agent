# J1 政府開放資料匯入：測試報告

- 日期：2026-11-04
- 截圖與輸出：`docs/過程截圖/J1_開放資料/`、`docs/過程截圖/J1_opendata_test輸出.txt`

## 1. 資料來源
| 項目 | 內容 |
|---|---|
| 提供單位 | 交通部觀光署「觀光資料庫」（政府資料開放平臺 data.gov.tw 資料集 7777 景點、7780 旅館民宿） |
| 下載網址 | `https://media.taiwan.net.tw/XMLReleaseAll_public/v2.0/Zh_tw/Attraction-json.zip`、`Hotel-json.zip` |
| 授權 | 政府資料開放授權條款－第 1 版（可免費使用，需註明來源） |
| 更新 | 官方每天更新 |
| 規模 | 景點 6,205 筆（營業中 6,044）、旅宿 15,652 筆；景點都有照片，旅宿含業者登記的房價區間 |

## 2. 做了什麼（ETL：擷取 → 轉換 → 載入）
| 步驟 | 內容 |
|---|---|
| 擷取 | 下載官方 zip；失敗時記錄原因，舊資料保留 |
| 轉換 | 讀 zip 內的清單 JSON（處理 BOM）；只留需要的欄位（名稱、縣市、地址、座標、介紹、照片最多 3 張、類型、房價區間）；歇業的不收；**不存統一編號** |
| 代碼對照 | 景點 28 類、旅宿 6 類，依《觀光資料標準 V2.0》第 14、20 節 |
| 載入 | 每筆算雜湊值和資料庫比對：新增／更新／不變（不寫）／下架（標記不刪除） |
| 紀錄 | 每次匯入一筆：觸發者、官方資料時間、各類筆數、失敗原因 |
| 排程 | 第一次啟動自動在背景匯入；n8n 流程 5 每天 04:30 更新 |
| 查詢 API | `/api/explore/cities`、`/api/explore/attractions`、`/api/explore/hotels`（縣市、關鍵字、預算、有照片、分頁）、單筆詳細；回應都附來源與授權 |
| AI 客服 | 新工具 `search_local_info`：查台灣各縣市景點／住宿；「台東」自動轉「臺東縣」；回答註明資料來源；規則寫明登記房價**不是報價** |

## 3. 測試結果
| 測試 | 結果 |
|---|---|
| `opendata_test.py`（假資料、暫存表，不動真實資料） | 23/23：解析與 BOM、歇業排除、不存統編、重複只算一次、新增／更新／不變／下架、壞檔案記錄失敗且保留舊資料、搜尋、類型中文、來源授權、預算篩選、縣市統計、AI 工具縣市轉換與房價註明、API 422／404、沒登入不能匯入、真實資料筆數不變 |
| 真實匯入（第一次啟動） | 景點 6,044 筆約 20 秒、旅宿 15,652 筆約 40 秒，全部新增 |
| 真實匯入（n8n 觸發第二次） | 景點 6,044 筆全部「不變」：比對機制有效，沒有重複寫入 |
| 既有測試 | AI 流程 29/29、多 Agent 24/24、API 67/67 照常通過 |

## 4. 遇到的問題
見錯誤紀錄 J1-1～J1-4：舊網址失效、zip 第一個檔案不是資料、類型代碼憑印象寫錯（查官方 PDF 修正）、測試差點把真實資料標成下架（改用暫存表）。

## 5. 限制
- 只有台灣的資料；沖繩、京都、首爾仍是模擬資料。
- 官方的照片放在各單位網站，網站改版可能失效；安裝版離線時看不到照片。
- 房價區間是業者登記的參考價，不是即時房價。

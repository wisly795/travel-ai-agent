# H5 Email 通知：測試報告

- 日期：2026-11-03
- 截圖：`docs/過程截圖/H5_Email通知/`

## 做了什麼
| 項目 | 內容 |
|---|---|
| 模擬信箱 | 新服務 Mailpit v1.33.0（收件畫面 http://localhost:8025，只開在本機）；信不會真的寄出去 |
| 寄信方式 | n8n 的 HTTP 節點呼叫 Mailpit 的寄信 API（不需要帳號密碼憑證） |
| 不重複寄 | 先寫通知中心；通知 API 回 `created=false`（已通知過）就不寄信 |
| 收件人 | 新報價 → 業務；每日報表 → 主管；採購待核准 → 依核准層級寄主管或業務；ERP 失敗 3 次 → IT（信箱設定在 `.env`） |
| 信件內容 | 主旨「[旅遊報價系統] …」、事件說明、後台連結、「模擬信件」註記 |
| 來源標籤 | 新報價通知加上「官網串接」來源 |

## 發現並修正
- Mailpit 清空信箱回傳純文字「ok」，測試腳本當成 JSON 解析失敗；改成解析失敗時當純文字處理。

## 未測與限制
- 真實寄信（Gmail、公司信箱）：要改成 n8n 的 Email 節點並設定 SMTP 帳號，需要真實帳號，未做。
- Mailpit 的信存在容器暫存，重啟後清空（模擬用途可接受）。

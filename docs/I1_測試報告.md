## 1. 做了什麼
| 項目 | 內容 |
|---|---|
| Git 版本控制 | 專案建立 Git 版本庫，第一次提交 213 個檔案 |
| 排除敏感與個人資料 | `.gitignore` 排除 `.env`（金鑰、密碼）、`登入資訊.txt`、安裝包，以及個人求職資料（學習筆記、作品集、職缺分析、專案狀態、有 Console 畫面的截圖） |
| 上傳前檢查 | 掃描所有要提交的檔案：沒有 `.env`、沒有 Claude 金鑰格式的字串、沒有超過 2 MB 的大檔 |
| CI 腳本 `tools/ci_run.sh` | 產生測試用隨機密碼 → 建置並啟動全部容器 → 等系統與 n8n 就緒 → 跑全部模擬測試 → 瀏覽器畫面測試 → 清除 |
| GitHub Actions `.github/workflows/ci.yml` | 每次上傳到 main 或開 Pull Request 自動執行；先檢查沒有金鑰檔被提交；失敗時印出容器紀錄；畫面測試截圖存成下載檔 |

CI 用「假 AI」（事先寫好的回應）測試，不需要 Claude 金鑰，也不花 API 額度。

## 3. 遇到的問題（詳見錯誤紀錄 I1-1～I1-4）
1. **本機沒有 Python**：腳本產生的隨機密碼是空的 → 改用 `openssl`。
2. **n8n 還沒準備好就開始測**：全新環境才會出現 → 等 n8n 紀錄出現「published workflows」再測。這正是 CI 的價值：開發版一直開著時從沒發生過。
3. **測試腳本計分時當掉**：檢查結果是 `None` → 一律轉成 True/False。
4. **PowerShell 傳多行提交說明失敗** → 改用說明檔。
5. **截圖 GitHub 頁面逾時**：GitHub 頁面一直有背景連線，等不到「網路安靜」→ 改成頁面結構載入完成就截圖。

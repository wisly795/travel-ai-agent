# 旅遊行程報價系統規格

全部資料為虛構，畫面標示「模擬資料，非真實報價」。

## 使用者
| 角色 | 可以做什麼 |
|---|---|
| 客人 | 查行程、看飯店、建立報價 |
| 業務 | 登入後查看報價紀錄、下載 CSV |

## 主要流程
1. 客人選目的地、人數、預算，查詢行程。
2. 選行程和飯店，填姓名，建立報價。
3. 後端計算總價並存入資料庫。
4. 業務輸入權杖，查看報價並匯出 CSV。

## 報價公式
- 行程費 = 每人價格 × 人數
- 房間數 = 人數 ÷ 2，無條件進位
- 住宿晚數 = 行程天數 − 1
- 住宿費 = 每房每晚價格 × 房間數 × 住宿晚數
- 總價 = 行程費 + 住宿費

價格一律由後端計算，前端送來的金額不採用。

## API
| 方法 | 路徑 | 用途 | 權限 |
|---|---|---|---|
| GET | `/api/health` | 檢查服務 | 公開 |
| GET | `/api/destinations` | 目的地清單 | 公開 |
| GET | `/api/packages` | 查行程 | 公開 |
| GET | `/api/hotels` | 查飯店 | 公開 |
| POST | `/api/quotes` | 建立報價 | 公開 |
| GET | `/api/quotes` | 報價紀錄 | 業務 |
| GET | `/api/quotes/export.csv` | 匯出 CSV | 業務 |

## 驗收標準
- 能依條件查到正確行程。
- 報價總價符合公式，且不接受前端自訂金額。
- 人數超出 1～20、行程與飯店目的地不符時回傳錯誤。
- 沒有權杖不能看報價，資料庫連線與 SQL 使用參數化查詢。
- 手機寬度可操作。

# H2 帳號密碼登入與角色：測試報告

- 日期：2026-11-03
- 截圖：`docs/過程截圖/H2_帳號登入/`

## 做了什麼
| 項目 | 內容 |
|---|---|
| 帳號 | `users`：業務／主管／管理員；第一次啟動自動建立 admin、manager、sales（初始密碼來自 `.env`，安裝時隨機產生並寫進登入資訊.txt） |
| 密碼 | PBKDF2-SHA256、20 萬次、每個密碼各自的隨機鹽；資料庫只存雜湊；至少 8 碼且英文加數字 |
| 登入工作階段 | 隨機 token，資料庫只存雜湊，8 小時到期；登出即失效；重新整理頁面保持登入（存在分頁的 sessionStorage） |
| 防暴力破解 | 連續錯 5 次鎖定 15 分鐘；帳號不存在與密碼錯誤回同樣訊息 |
| 登入紀錄 | 每次成功／失敗、原因、IP |
| 帳號管理（管理員） | 新增、停用／啟用、重設密碼；停用或重設會讓該帳號立即登出；不能停用自己 |
| 角色權限 | 業務：後台與一般核准；主管：可核准大額；管理員：帳號管理，不能核准採購 |
| 操作者紀錄 | 報價狀態變更記錄 `changed_by`；採購核准記錄 `decided_by` |
| 服務權杖 | 原本的權杖保留給 n8n 與測試程式（系統整合用），自動化權杖不能進後台 |

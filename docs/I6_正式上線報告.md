## 部署時遇到的問題
- 安裝包沒有 `docker-compose.prod.yml`：預演是在專案資料夾做的，打包清單沒加。上傳前檢查安裝包內容時發現，補進 `tools/build_installer.py` 後重新打包。（和 J4-1 漏放 supplier 是同一類問題：新增檔案要記得加進打包清單。）
- 從 Git Bash 呼叫 gcloud 會因為路徑有空格失敗，改用 PowerShell。

## 帳號與密碼
- 正式版密碼全部重新隨機產生，和開發版不同；存在本機 `prod.env`（不上傳 GitHub、不在安裝包裡）與主機 `/opt/travel/.env`（權限 600）。
- 業務後台用 `sales`／`prod.env` 的 `SALES_PASSWORD` 登入。

## 恢復方案（出問題時）
- 只撤旅遊系統：`cd /opt/travel && sudo docker compose -p travel down`，Caddyfile 刪掉 travel 那一段後 `caddy reload`。
- 揮發度系統受影響：`cat /opt/demo/Caddyfile.bak-20261104-0446 > /opt/demo/Caddyfile`、`caddy reload`；必要時用 `/opt/backup/voldemo-20261104-0446.sql` 還原資料庫。

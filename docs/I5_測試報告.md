# I5 前端改用 React：測試報告

- 日期：2026-11-04
- 截圖：`docs/過程截圖/I5_React/`

## 1. 做了什麼
| 項目 | 內容 |
|---|---|
| 技術 | React 18＋Vite 5；元件測試 Vitest＋Testing Library |
| 結構 | `App.jsx`（分頁）、`Chat.jsx`（AI 客服）、`Customer.jsx`（查行程與報價）、`Policy.jsx`（旅遊規定）、`staff/`（後台 9 個分頁各一個元件）、`charts/Charts.jsx`（儀表板圖表）、`api.js`（呼叫 API、格式化、登入狀態） |
| 改寫方式 | 原本用 JavaScript 直接改畫面（729 行），改成「資料（state）決定畫面」：資料變了 React 自動更新畫面 |
| 圖表 | 原本用程式一個一個產生 SVG 元素，改成 React 元件（JSX 寫 SVG），規格不變：柱寬 24px、圓角、細格線、滑過提示、附數據表格 |
| 共用載入邏輯 | `useStaffData`：每個後台分頁各自載入資料；做完一個動作（成交、核准…）全部分頁重新載入 |
| 不變的部分 | 所有元素 id、class、文字都和原本一樣，所以原本的瀏覽器畫面測試不用改就能驗證 React 版 |
| 建置 | Docker 多階段：第一階段用 Node 跑前端測試再建置，第二階段的 Python 映像只放建置好的檔案；安裝的電腦不用裝 Node |

## 3. 遇到的問題
1. **每次畫面更新都重新載入資料（差點發生）**：把「登入過期時要做的事」寫成每次重新產生的函式，會讓所有分頁以為設定變了而一直重新載入。改用 `useCallback` 固定函式。這是 React 很常見的坑。
2. **前端測試 3 項失敗**：測試環境（jsdom）沒有瀏覽器的「捲動到元素」功能，不是程式錯；在測試裡補一個空的版本。
3. **舊截圖腳本過時**：`ui_h3_shots.py` 還在檢查 5 張 KPI 卡片、2 種報價來源，但 H4、H6 已經改成 6 張、3 種（原生版也會失敗），更新預期值。
4. **截圖資料夾名稱錯誤**：PowerShell 傳 `I5_React\子資料夾`，反斜線到了容器裡變成資料夾名稱的一部分，改用 `/`。
5. **測試資料被用完**：`ui_h2_shots.py` 第二次執行時，「待主管核准的大額採購單」已在第一次被核准，找不到可核准的單；屬於測試資料狀態，展示前會重建示範資料。

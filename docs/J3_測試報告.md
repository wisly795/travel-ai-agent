# J3 旅遊網站前台改版：測試報告

- 日期：2026-11-04
- 截圖：`docs/過程截圖/J3_旅遊網站/`（01～18）

## 1. 為什麼改版
使用者看了原本的畫面（分頁式、表單為主）覺得「不太像一個旅遊網站」。改成一般旅遊網站的樣子：大圖首頁、搜尋、行程卡片、目的地照片、詳細頁、聊天泡泡；業務後台另外放在 `/admin`。

## 2. 做了什麼
| 頁面 | 網址 | 內容 |
|---|---|---|
| 首頁 | `/` | 大圖（開放資料的七星潭照片，標明來源）、搜尋（目的地、人數、預算）、8 個精選行程、探索台灣（8 個縣市照片與數量）、特色介紹、和 AI 聊聊 |
| 精選行程 | `/tours` | 篩選條件放在網址（可分享、重新整理不會不見），沒有結果時提示 |
| 行程詳細頁 | `/tours/:id` | 行程資訊、選擇住宿、**改人數／飯店／日期就即時試算（價格由後端計算）**、建立報價單；台灣行程顯示附近景點（開放資料）；供應商參考價（爬蟲資料，標明不是報價） |
| 探索台灣 | `/explore` | 22 個縣市照片卡片與景點、旅宿數量 |
| 縣市頁 | `/explore/:city` | 景點／住宿切換、關鍵字（海、步道、溫泉…）、住宿預算、載入更多（分頁）、照片載入失敗顯示「暫無照片」 |
| 旅遊須知 | `/guide` | 規定向量搜尋（沿用原元件） |
| AI 客服 | 每一頁右下角 | 聊天泡泡，點開才顯示；換頁時對話保留；可切換單一／多 Agent |
| 業務後台 | `/admin` | 原後台全部功能，新增「資料與爬蟲」頁：開放資料匯入紀錄、爬蟲紀錄、價格變動、管理員手動執行 |

設計：
- 品牌「晴空旅遊」（和模擬官網一致）；顏色、圓角、陰影都用 CSS 變數，改品牌只要改一個地方。
- 海外目的地（沖繩、京都、首爾）沒有可授權的照片，**自己畫 SVG 插畫**，不從網路抓圖；台灣景點用開放資料的照片並註明來源。
- 技術：React Router（單頁應用）；後端讓 `/tours`、`/explore`、`/admin` 等網址都回同一個頁面，重新整理不會 404。
- 手機版：選單收合成按鈕、搜尋欄改直排、詳細頁改單欄、聊天視窗佔滿寬度。

## 4. 遇到的問題
見錯誤紀錄 J3-1～J3-6：CSS 優先順序讓白字變深色、卡片文字斷行、單選圓點跑版、舊樣式影響新網站、工具名稱顯示英文、CI 沒有開放資料。前 3 個都是**看截圖才發現**的，自動測試不會報錯。
